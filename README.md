# Youtube-bookmark-extension

A simple Chrome extension that allows users to bookmark specific timestamps in YouTube videos and easily return to them whenever they want.

This project was developed as part of my personal learning journey in web development and Chrome extension development.


## Overview

The YouTube Bookmark Extension provides a simple way to save important moments from YouTube videos. Instead of manually searching for a particular part of a video again, users can save timestamps and access them directly through the extension popup.

This project is intended primarily for personal use, learning, and technical skill development.



## Features

- **Save Bookmarks** – Save the current timestamp of a YouTube video.
- **View Bookmarks** – Display saved timestamps in the extension popup.
- **Play from Timestamp** – Return directly to a previously bookmarked moment.
- **Delete Bookmarks** – Remove bookmarks that are no longer needed.
- **Automatic Storage** – Save bookmark data using Chrome Storage API.


## Techn stacks i used

The project uses the following technologies and browser APIs:

- **HTML** – Structures the extension popup.
- **CSS** – Handles the visual styling and layout.
- **JavaScript** – Implements the extension's functionality and logic.
- **Chrome Extensions API** – Allows communication between the extension and the browser.
- **Chrome Storage API** – Stores bookmark information.
- **Chrome Tabs API** – Retrieves and interacts with the active browser tab.
